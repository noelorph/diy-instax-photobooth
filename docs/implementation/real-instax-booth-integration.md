## Implementation choices retained for the next verification pass

Keep one mode-specific printer owner across Admin-to-Booth navigation; subscription cleanup only unsubscribes, while explicit release disconnects and discards the terminal owner. A validated handoff UUID remounts cached controllers without granting authority or exposing the scoped secret. Equipment epochs fence late healthy measurements after camera/network loss. These choices address observed software races without changing access contracts.

After waiting for an in-flight poll, recheck the actual status timestamp against the 5,000-ms readiness window before crossing the send boundary. Once the calibrated send routine begins preflight, ambiguous failure is possible delivery; it cannot be downgraded to a clean non-send. Normal recognized loading, including the recorded closed black-cover operationInfo=2/result=127 status, preserves already-proven normal safety. It cannot upgrade false safety, clear an interrupted job or settle Pending. Capture the reload observer before each exchange so an older in-flight response cannot become a new request's baseline. A closed-cover local load fault may retire only after its matching server-bound request is acknowledged.

Physical reload uses separate `observe_reload` authority and metadata, not a print observation. Preserve originating grant attribution, first-confirmation identity and receipt-before-fresh-binding semantics. These approved choices are recorded in ADR-0035 and the replacement contract; no new physical recovery or clearing procedure follows from them.
