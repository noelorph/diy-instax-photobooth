## Global constraints

- Use the existing /booth route and Admin Event setup. Real printing is enabled only by explicit nonproduction server and owner-controlled database settings; failed connection never falls back to simulation. Keep both disabled in production regardless of flags/browser hints.
- Preserve accepted normal ejection, physical-last-sheet, known-empty-negative and normal-reload results. Do not repeat them merely to start integration or call them untested. New software checks are not physical qualification.
- Ten prints per original/additional Film Package; an unresolved attempt holds one unit and the sole printer slot. Full ejection counts once even if unusable. Reload changes readiness only.
- “Print complete” follows matching full-ejection evidence and server acknowledgement; show it for 3 seconds, then end the Guest Session. Acceptance, elapsed time and film count cannot establish success. Welcome still requires all remaining guards.
- Preserve attempt, dispatch, printer, connection-generation, observation and actor/run identity; immutable terminal results, conflict audit, receipt replay, lock order and one-send behavior. No resend after a lost reply, page reload or ambiguous transport failure.
- Unknown possible delivery stays Pending. Reconnect, idle, reload, dismissal and an unqualified inspection flag cannot establish old-job clearance. No reset/cancel/reload command is introduced.
- Physical Finish stays Finishing until both outcome and printer safety are settled. Starting a new run/Event cannot erase an unsafe physical-job block. Nonproduction reconciliation of already-authorized work uses its pinned policy even if a mode is later disabled; that never grants new dispatch authority.
- Readiness expires at 5,000 ms; current visible Booth reporting remains every 2,000 ms. Preserve camera permission gestures, 75/90-second Guest inactivity behavior, independent blockers, explicit pause and Finish races.
- Guest JPEGs stay in browser memory and direct printer transport. Journals, HTTP, database, logs and test artifacts contain metadata only. Preserve existing image cropping/encoding and transport calibration.
- Keep media uploads disabled and preserve their commit/cleanup safeguards. No full F6/F8 completion claim, schema reset, legacy migration rewrite, deployment or issue closure. Add scoped forward migrations for this work; F8 must later include them in its baseline.
- No physical printing, reset or reload trials during implementation. Actual-printer/actual-iPad tests require a separate authorized task. Unit/integration/browser checks use synthetic printer responses.
- Before implementation, read AGENTS.md and the installed Next.js route-handler, server/client-boundary and environment-variable guides. Record any newly discovered durable decision with the owner before changing its authority documents; approval of this package covers the decisions explicitly stated here.

## Review focus

1. A low-level timeout may retire transport without delivering a normal disconnect callback: readiness and observers must still invalidate — task 2 tests.
2. A pre-execute failure may follow image/preflight writes: it must not be mislabeled definitely_not_sent — task 2 tests.
3. Lost server acknowledgement before a reconnect differs from replay of an already committed receipt: preserve the receipt without accepting fresh stale evidence — tasks 1 and 3 tests.
4. An automatic reload can race manual confirmation, request replacement or generation change: exactly one matching request changes, with no other blocker cleared — task 4 tests.
5. Normal completion can overlap final capacity, camera loss, Pause, Finish or a mode change: count once, preserve the correct screen and admit no forbidden next Guest or lifecycle bypass — tasks 1 and 3 tests.
