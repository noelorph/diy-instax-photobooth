# Reserve print allowance before printing

The booth creates both a Print Reservation against the Event's allowance and a Film Reservation against shared Film Stock before sending a Guest print to the printer. A Test Print creates only a Film Reservation and uses a generated calibration image. The authorized booth browser reports printer feedback; the server accepts a film-ejection report only for the matching pending attempt. Reliable detection of physical film ejection consumes the held allowance and sheet and provisionally confirms a Guest print; the Admin can reclassify an unusable ejected sheet as Wasted Film, returning the allowance while keeping the sheet consumed. Confirmed ejection closes the Guest Session and discards its photo, so a Wasted Film replacement starts a new Guest Session with a new Capture rather than reopening the prior session. A clear rejection before film is used releases both holds. An uncertain result keeps the holds and pauses the booth until the Admin inspects the printer and resolves the counts. A browser reload or crash after reservation is uncertain if the server cannot prove whether the print command reached the printer; the booth never resends it automatically. Reliable completion feedback is a launch requirement so routine Guest Sessions do not need Admin confirmation. This protects allowance and stock against duplicate commands and unclear printer responses, at the cost of requiring manual recovery in ambiguous cases.
