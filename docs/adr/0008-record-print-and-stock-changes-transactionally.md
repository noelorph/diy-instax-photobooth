# Record print and stock changes transactionally

> **Current scope (2026-10-21):** Atomic/idempotent accounting remains; stock-specific operations and formulas are superseded. [ADR-0025](0025-package-accounting-and-booth-recovery.md) and the [replacement contract](../superpowers/specs/2026-10-21-package-accounting-booth-recovery-design.md) control conflicting behavior. The original decision below is retained as history.

Creating, confirming, releasing, and resolving Print Attempt reservations updates Event allowance and shared Film Stock in one Postgres transaction, with idempotency keys for repeat requests. The system retains append-only entries for film additions, reconciliations, Test Prints, Guest print outcomes, and Wasted Film corrections so current totals can be inspected and reconciled. The Admin resolves all pending Film Reservations before entering an observed physical sheet count and a reason for reconciliation; additions to stock remain possible during a pending attempt. The difference becomes a ledger entry rather than silently replacing history. This favors consistent, auditable counts over editing counters directly, at the cost of more explicit transition logic and journal maintenance.
