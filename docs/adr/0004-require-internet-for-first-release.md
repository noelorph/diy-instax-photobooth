# Require internet during the first release

The first release requires an internet connection for guest sessions and print accounting. When connectivity fails, new sessions pause; a selected photo waiting to print stays only in browser memory while the page remains loaded until service returns or the Admin cancels the session. A reload loses that photo. The review inactivity timeout is suspended during this hold. If command delivery is known not to have happened, restored service and availability return the Guest to review, where Print requires an explicit action rather than an automatic send. If connectivity fails after a print command or command delivery cannot be ruled out, the outcome is uncertain and requires Admin resolution. This keeps allowance accounting consistent with the server at the cost of pausing the booth during venue outages.
