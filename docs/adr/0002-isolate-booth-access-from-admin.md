# Isolate Booth Mode access from the admin

Entering Booth Mode ends the Admin login on the booth iPad and gives that device a revocable Booth Access Grant limited to its Live Event. The grant cannot read Client contact details or authorize Admin actions. It survives an ordinary reload or brief connection loss, but pausing or ending Booth Mode revokes it; a paused Event remains Live, and resuming requires Admin sign-in and a new grant. The Admin also starts iPad Guided Access to keep Guests in the browser; the target-device trial must show that Guests cannot use browser navigation to reach Admin pages. Returning to management requires Admin sign-in. An Admin session on another device may remain active so the Admin can manage the Live Event. This separates guest capture and printing from Event administration while allowing the booth to operate after the iPad Admin session ends.
