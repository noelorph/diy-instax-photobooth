# Isolate Booth Mode access from the admin

Entering Booth Mode ends the Admin login on the booth iPad and gives that device access limited to its Live Event. The Admin also starts iPad Guided Access to keep Guests in the browser; the target-device trial must show that Guests cannot use browser navigation to reach Admin pages. Returning to management requires Admin sign-in. An Admin session on another device may remain active so the Admin can manage the Live Event. This separates guest capture and printing from Event administration while allowing the booth to operate after the iPad Admin session ends.
