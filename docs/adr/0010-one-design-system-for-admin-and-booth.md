# Use one design system for Admin and Booth Mode

**Refined, 2026-11-06:** [ADR-0034](0034-use-november-screen-reference-in-implementation-plan.md) retains the shared-system decision and replaces ADR-0033’s presentation target with the November reference. Admin keeps its saved light/dark preference; Booth presentation remains state-specific and independent.

Admin pages and Booth Mode will share semantic tokens, typography, icons, and component behavior under [the main plan’s presentation contract](../superpowers/plans/2026-10-24-issue-10-implementation-plan.md#screen-reference-and-presentation-contract), while each has layout and control rules suited to its user. The Admin needs dense, scannable management views and a saved light/dark preference; Guests need a consistent dark camera experience with large touch controls, independent of that preference. Separate visual systems would let the two surfaces drift, while forcing identical layouts would make the booth feel like a dashboard. The shared system is the UI/UX source of truth; the PRD retains product behavior and the architecture retains technical boundaries.
