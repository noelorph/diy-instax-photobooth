# Decision index

[ADR-0025](0025-package-accounting-and-booth-recovery.md) and its [replacement contract](../superpowers/specs/2026-10-21-package-accounting-booth-recovery-design.md) govern the current approved target. Earlier ADRs preserve their original decision text; notices below their titles identify superseded scope. Historical “Accepted” labels describe acceptance at that time, not authority to restore removed features.
