# Use Geist typography across Admin and Booth Mode

The original design system chose DM Sans as the shared UI family. During the approved Admin refresh, the owner selected the typography of the CodeRabbit app as a reference and confirmed that the change applies to both Admin and Booth Mode. The [CodeRabbit app stylesheet inspected on 2026-10-15](https://assets.coderabbit.ai/ui/releases/release-v202610150211-38669680440-1/assets/revalidated/startup-dependencies~main~index~index~MountedSubscriptionDetailDrawer~MountedPlanDetailDraw~lf11asmo-R6AtqRr0.css) sets its default UI family to Geist Variable. [Vercel distributes Geist under the Open Font License](https://vercel.com/font).

Use Geist Sans Variable as the single UI family, with a system sans-serif fallback, across public Admin auth, authenticated Admin pages, and Booth Mode. Load it from locally served assets through the root Next.js layout. Adopt the reference's compact Admin text rhythm while retaining the design system's larger Booth instruction and countdown roles, 200% zoom readability, and tabular numerals for counts and times. Do not add Geist Mono or another display family merely to mimic a code-review product.

This replaces the DM Sans family and the previous Admin text line heights in [DESIGN_SYSTEM.md](../../DESIGN_SYSTEM.md). It preserves [ADR-0010](0010-one-design-system-for-admin-and-booth.md)'s single-system decision and changes no product behavior, theme colors, or Booth development gate. The [Admin UI refresh spec](../superpowers/specs/2026-10-15-admin-ui-refresh-design.md) includes the initial migration and typography checks.
