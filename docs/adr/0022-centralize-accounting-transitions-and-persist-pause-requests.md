# Centralize accounting transitions and persist Booth pause requests

The contracts for [issue #9](https://github.com/noelorph/diy-instax-photobooth/issues/9) use server-invoked database operations for every Event lifecycle, reservation, stock, and Print Attempt mutation. These operations lock the Event and shared stock balance in a fixed order, validate the actor and transition, apply idempotency, and commit the resulting holds, ledger entries, and activity together. Admin reads and Draft edits continue through provisioned Admin RLS; the Booth Access Grant reaches only narrow server endpoints. Restricted accounting RPC functions are callable only by the server-side privileged role, with explicit function grants and input checks. The [contract design](../superpowers/specs/2026-10-16-accounting-access-printer-contracts-design.md) defines the transition and endpoint shapes.

A Booth run records `PauseRequested` when a stop arrives during a reserved Print Attempt. New Guest work is refused immediately. The matching attempt may finish or become Uncertain; the run then becomes `Paused` and its grant is revoked. This makes the stop/reservation ordering durable across browser reloads and remote Admin devices. A failed Admin-to-Booth handoff leaves the Live Event paused with no active grant; the initial grant activates only after local Admin sign-out and a Booth cookie receipt confirmation. Resume requires Admin sign-in and a new grant.

An Admin may resolve an Uncertain Print after physical inspection as ejected or unused, recording the actor and reason. This is recovery for an exceptional attempt. It does not approve routine manual confirmation or change the [ADR-0021](0021-move-print-qualification-to-integration-checkpoint.md) checkpoint: production printer-backed Booth Mode, Test Prints, stock consumption, and Confirmed Print accounting remain gated on a physically validated completion approach. Command acknowledgement, printer Film Remaining, and the unverified `12 7f` field remain insufficient evidence of complete ejection.

This decision extends [ADR-0002](0002-isolate-booth-access-from-admin.md), [ADR-0007](0007-route-booth-requests-through-server.md), [ADR-0008](0008-record-print-and-stock-changes-transactionally.md), and [ADR-0014](0014-stop-booth-before-print-reservation.md). It supersedes none of them.
